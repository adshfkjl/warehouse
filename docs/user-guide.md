# WMS 管理界面操作说明

## 登录和工作台

打开 `Warehouse.Wms.Web` 后使用 WMS 账号登录。工作台显示库存件数、待处理任务、库位利用率、设备状态和未结异常。页面中的状态是 WMS 业务状态；PLC 指令和寄存器时序只能由设备网关执行。

## 入库和出库

入库页面用于建单、收货、绑定托盘、选择上架库位和查看设备任务；设备未返回确定完成结果前，库存保持待入库状态。出库页面用于建立需求、分配批次/托盘/库位、查看下架和装载点复核；复核差异必须进入异常处置或高风险审批。

## 库存、任务和盘点

库存与库位页面用于查询余额、库位状态和库存流水。设备任务页面按已排队、执行中和需处置分组；`PhysicalStateUnknown` 任务必须先对账，不得直接重试或释放资源。盘点页面支持范围任务、明盘/盲盘、复盘和差异审批；授权通过后才生成库存调整流水。

## PDA 模式

PDA 模式只负责扫描或输入托盘、库位编码，然后调用同一套 WMS 业务 API。浏览器不连接 PLC、不写寄存器、不实现设备等待或重试时序。

## 异常处置

异常中心展示来源、任务号、设备任务号、托盘/库位、物理状态和资源锁。处理未知物理状态时先查看设备观察或执行对账；人工确认、停止请求和库存校正需要二次授权并填写原因。所有动作都必须保留审计记录。

## 验收记录

自动化页面检查只能证明静态入口、交互边界和 PLC 控制隔离。负责人仍需按入库、出库、移库、盘点差异、异常和权限流程完成人工确认，确认结果记录为 `HUMAN_CONFIRMED`。
